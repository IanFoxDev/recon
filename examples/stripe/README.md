# Example: a shop's ledger against a Stripe export

`data/` is generated by `go run ./cmd/recon-gen -out examples/stripe/data -seed 1
-payments 200 -planted 2`: 200 payments that reconcile, two differences of each kind,
and `expected.json` with the keys of those differences.

```bash
cd examples/stripe
RECON_UID=$(id -u) RECON_GID=$(id -g) docker compose run --rm recon
open out/report.html     # or xdg-open
docker compose down -v
```

recon exits with 1 because there are differences. `out/report.json` lists them; they
are the keys in `data/expected.json`.
