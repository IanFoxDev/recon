# Contributing

## Running locally

You need Go 1.26 or later and Docker.

```bash
make postgres-up   # PostgreSQL on 55433 for the SQL and end-to-end tests
make check         # go vet, go test -race, golangci-lint (in Docker)
make postgres-down
```

Without the database the SQL and end-to-end tests are skipped, not failed, so check
the output if a run looks fast. The Makefile sets `RECON_TEST_PG_DSN` for the container
above.

```bash
go test ./cmd/recon -update                              # rewrite the golden reports after an intended change
go run ./cmd/recon-gen -out /tmp/demo -seed 7 -planted 3 # a ledger and an export with known differences
cd examples/stripe && docker compose run --rm recon      # the example, end to end
```

## Where things are

| Path | What |
|---|---|
| `internal/money` | Parsing and formatting amounts; `iso4217.go` is generated by `go run ./internal/money/gen` |
| `internal/config` | `recon.yaml`, its checks and the export profiles |
| `internal/source` | CSV and PostgreSQL readers |
| `internal/match` | Pairing rows and the categories of differences |
| `internal/report` | JSON, CSV and HTML |
| `internal/demo`, `cmd/recon-gen` | Generated test data with known differences |
| `cmd/recon/testdata` | The example shop behind the golden reports |

## Adding an export format

1. Add a profile in `internal/config/profiles.go` with the columns and the unit of
   amounts, and a link to the provider's documentation in a comment.
2. Add a sample file with made-up values to `internal/source/testdata` and a test that
   reads it.
3. Document it in `docs/config.md`.

## Pull requests

- One logical change per pull request.
- Commit messages follow [Conventional Commits](https://www.conventionalcommits.org/).
- No floats for money, anywhere. The same input must give the same report.
- `make check` passes with the database up. Add a line to `CHANGELOG.md`.
